# Asset provenance policy

Still includes a substantial collection of illustrations and other visual assets. Repository history does not currently provide a complete per-file provenance ledger, so this document establishes the rule for assets going forward without making unsupported ownership claims about existing files.

For every new third-party or commissioned asset, record:

- repository path or path pattern
- creator/source
- date obtained
- license or written permission
- attribution requirements, if any
- whether modification and redistribution are allowed

Do not add an asset when its usage rights are unclear. Do not copy visual assets from search results, social platforms, other applications, or stock sites without confirming the applicable license or permission first.

Existing assets should be inventoried against this policy before Still is redistributed outside the project. Until that inventory is complete, the presence of a file in this repository should not be interpreted as a grant of reuse rights.
